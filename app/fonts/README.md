# UNDRAM typography

Locally served with `next/font/local`; no runtime requests to a font CDN.

- Cormorant Garamond: variable upright and true italic, weight 300–700.
  Source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
  License: OFL-CormorantGaramond.txt
- Manrope: variable upright, weight 200–800.
  Source: https://github.com/google/fonts/tree/main/ofl/manrope
  License: OFL-Manrope.txt

Downloaded 2026-10-15. The upstream variable TTFs were converted to WOFF2 using FontTools/Brotli without removing glyphs. Verified the complete Mongolian Cyrillic alphabet, including Ө/ө and Ү/ү, and ₮ in all three font files. No production dependency was added.
